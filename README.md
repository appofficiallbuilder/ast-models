# ast-models

AI model files for the AST PRO Android app. The GitHub Action "Publish AI models" downloads each model from its upstream source, verifies SHA-256 and size, and publishes them as the Release `models-v1`.

Sources and licences: Bandit v2 (CC BY-SA 4.0), TIGER-DnR (Apache-2.0), SCNet / SCNet-large (MIT), Spleeter (MIT). See `ATTRIBUTION.md` inside the Release after the workflow has run.
